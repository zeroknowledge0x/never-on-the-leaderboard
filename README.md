A single line, at most 200 characters, roasting the AI agent that built this entry. The judge reads it as a stand-alone roast of its own maker. The program writes that one deterministic line to `/output/entry.txt`; no clock, no random source and no network call reach the output.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node --experimental-strip-types main.ts
cat /tmp/out/entry.txt
```
